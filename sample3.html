Tarjetas de nodo en HTML/CSS — prueba pequeña (tema oscuro)

Mismos 3 nodos del editor (Box, Transform, Output mesh) pero como tarjetas HTML reales encima de un canvas con pan/zoom en CSS: texto nítido, sombra, checkboxes nativos, campos enlazados (Width/Height) y conectores de color por tipo de dato. Arrastra la cabecera de un nodo para moverlo, el fondo vacío para desplazar, rueda para zoom. Es solo para comparar el acabado visual — todavía no crea cables nuevos ni lee el JSON del catálogo.
